# EconomicsScraper
A script that scrapes from various websites and preforms calculations based on the scraped values.

To run, Python and Pip must be installed. After that, you just need to download build_windows_exe_fixed.bat for windows or build_mac.command for mac and the other two codes and it should work. 

After downloading, save to a folder somewhere and click the .bat file and run it. Wait until it's finished and a new folder called "Dist" should appear. Inside is either a .EXE file or a .APP file depending on whether it's a windows or mac. Just double click that and the program will run.

Make sure the directory is in the correct place that you want to save the Excel file to and then just select which website you want to scrape from
